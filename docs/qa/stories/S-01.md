## 1. Requirement & Acceptance Criteria

### Acceptance Criteria
* **AC1**: Khung dịch vụ máy chủ Backend (FastAPI / Uvicorn) khởi động thành công tại cổng 8000, cung cấp tài liệu API Swagger tại `/docs`.
* **AC2**: Ứng dụng giao diện người dùng Frontend (React 18 / Vite 5) biên dịch thành công và phục vụ tại cổng 5173, có cấu hình Reverse Proxy gọi API backend không bị chặn CORS.
* **AC3**: Cơ sở dữ liệu SQLite (`ev_csms.db`) tự động khởi tạo các bảng dữ liệu ban đầu hoặc nâng cấp qua migration script mà không phát sinh lỗi.
* **AC4**: Endpoint kiểm tra sức khỏe `GET /api/v1/health` phản hồi mã HTTP 200 với trạng thái `"status": "healthy"` và `"database": "connected"`.
* **AC5**: Cung cấp cấu hình Docker và Docker Compose Staging (`docker-compose.staging.yml`, `backend/Dockerfile`, `frontend/Dockerfile`, `frontend/nginx.conf`) cho phép khởi chạy đồng bộ toàn bộ cụm dịch vụ.
* **AC6**: Quy trình CI tự động hóa (`.github/workflows/ci-staging.yml`) kiểm tra chất lượng mã nguồn: chạy toàn bộ 89 bài kiểm thử backend và biên dịch giao diện frontend.

### Non-functional Requirements
* Thời gian khởi động hệ thống dưới 5 giây trên máy tính cá nhân tiêu chuẩn.
* Hỗ trợ cài đặt trên hệ điều hành Windows, Linux và macOS qua `requirements.txt` và `package.json`, cũng như môi trường Docker Linux container.
