## 1. Requirement & Acceptance Criteria

Là Admin/Operator, tôi muốn gửi lệnh Reset tới trụ đang kết nối và nhận đúng phản hồi của lệnh đó để quản lý trụ từ CSMS.

* **AC1 — Gửi CALL**: Dispatcher sinh UUID message ID, đóng gói CALL bằng `build_call` và gửi qua kết nối OCPP đang hoạt động.
* **AC2 — Ghép phản hồi**: CALLRESULT đúng message ID trả payload cho bên gọi; CALLERROR cùng ID được chuyển thành exception. Message khác trên kết nối tiếp tục được gateway xử lý trong lúc dispatcher chờ.
* **AC3 — Timeout**: Quá hạn chờ mà chưa có kết quả thì dispatcher ném `TimeoutError`; timeout mặc định lấy từ `OCPP_CALL_TIMEOUT_SECONDS`.
* **AC4 — API Reset**: `POST /api/v1/chargers/{code}/reset` nhận `Soft` hoặc `Hard`, chỉ cho Admin/Operator; trụ offline trả 409 mà không gọi dispatcher.
* **AC5 — Kết quả API**: CALLRESULT được trả thành công; timeout trả HTTP 504. CALLERROR được báo thành HTTP 502.
